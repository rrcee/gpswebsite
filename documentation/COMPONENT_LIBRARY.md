# COMPONENT LIBRARY

Identify reusable UI components across the new site design.

## 1. Global Components
- **Header / Mega Menu:** Sticky top navigation with multi-column dropdowns for Academics and Admissions.
- **Footer:** Dark-themed footer containing all secondary links, social icons, and contact info.
- **Breadcrumb:** Simple navigational trail at the top of interior pages.

## 2. Card Components
- **Notice Card:** Date, Title, Download PDF link. (Used on Home & Notice Board)
- **Faculty Card:** Photo, Name, Subject/Role. (Used on Faculty page)
- **Gallery Card:** Thumbnail image, Album Title, Photo count overlay.

## 3. Informational Components
- **Timeline:** Vertical timeline used for School History.
- **Accordion / FAQ:** Collapsible sections for Fee Structure and rules.
- **Data Table:** Used for Mandatory Disclosure and Staff details.
- **Hero Banner:** Full-width image/video banner with title and CTA.
